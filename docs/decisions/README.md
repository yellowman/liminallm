# decisions

Why the unusual invariants in `SPEC.md` exist. The SPEC states each rule and
at most one sentence of rationale; the file here carries the evidence and
the failure narrative that earned it. `docs/ISSUES.md` holds the
tranche-by-tranche forensic record; a decision file distills the part of
that record a future editor needs before weakening a rule.

Read a decision file before proposing to simplify the rule it defends.
